🧺 Go-Laundry — Web Application

Developed a full-stack laundry management web application using Java (Servlet & JSP) with MVC architecture pattern.

🔧 Tech Stack:
• Backend: Java Servlet, JSP, JDBC
• Database: MySQL
• Server: Apache Tomcat
• Build Tool: Apache Maven
• IDE: NetBeans

✨ Key Features:
• User authentication system (Register & Login)
• Laundry service management with real-time pricing calculation
• Order tracking with status history (Pending, Proses, Selesai)
• Payment confirmation system
• Customer review & rating system
• Role-based access (User, Admin, Kurir)

📐 Architecture:
Implemented Object-Oriented Programming principles including Inheritance, Interface, and Polymorphism through a layered architecture: Model → DAO (JDBC) → Servlet → JSP.
